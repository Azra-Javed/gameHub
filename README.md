# 🎮 GameHub

A modern video game discovery web app built with **React**, **TypeScript**, **Vite**, and **Material UI**.

🔗 **Live Site**: [gamehubazra.netlify.app](https://gamehubazra.netlify.app)

##  Features

- Browse games by platform, genre, and rating  
- Responsive and mobile-friendly UI  
- Smooth search and filtering experience  
- Clean Material UI design system

## 🛠Tech Stack

- React  
- TypeScript  
- Vite  
- Material UI

## Future Improvements

- Add infinite scroll or pagination  
- Implement authentication and favorites  
- Integrate real-time data updates
